# Blog API

Node.js ve Express.js kullanılarak geliştirilmiş RESTful Blog API projesidir.

## Özellikler

* Kullanıcı kayıt ve giriş işlemleri
* E-posta doğrulama
* JWT ile kimlik doğrulama
* Profil bilgilerini güncelleme
* Profil resmi yükleme
* Blog yazısı oluşturma, güncelleme ve silme
* Blog yazılarını listeleme
* Yazı arama ve filtreleme
* Beğeni işlemleri
* Yorum ve yorumlara cevap verme
* MongoDB veritabanı kullanımı


## Kurulum
Projeyi indirdikten sonra:

```bash
npm install
```
`.env` dosyasını oluşturup gerekli bilgileri ekleyin.

Projeyi çalıştırmak için:

```bash
npm start
```
API testleri **Postman** üzerinden yapılabilir.

## Proje
Bu proje, Node.js backend geliştirme ve REST API oluşturma pratiği amacıyla geliştirilmiştir.
